# Security policy

## Supported release

Security fixes currently target the latest 0.x release.

## Reporting a vulnerability

Do not open a public issue containing a vulnerability exploit, credential,
private key, identifiable patient information, or controlled-access dataset.
Contact the maintainer privately through the security-reporting channel of the
repository host once the repository is published.

## Scope and limitations

Melinoe is research software, not a medical device. Project Vault and contained
execution reduce common exposure risks but do not defend against a compromised
kernel, malicious administrator, or careless export of decrypted data. Users
remain responsible for ethics approvals, data-use agreements, backups, key
custody, and institutional security policy.
