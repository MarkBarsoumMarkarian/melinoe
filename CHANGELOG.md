# Changelog

All notable changes to Melinoe are documented here.

## 0.4.0 - 2026-09-27

First public research-software release candidate.

### Added

- Typed OncoGraph manifests and deterministic OncoGuard validity checks.
- Local dashboard, API, CLI, encrypted Project Vault integration, contained
  execution, research-state snapshots, and a tamper-evident ledger.
- Signed workflow locks, signed offline knowledge packs, reversible
  checkpoints, and validity-gated Slurm/Apptainer handoffs with RO-Crate 1.3
  metadata.
- Reusable cohort-native survival synthesis with censoring-aware Cox models,
  proportional-hazards diagnostics, REML/Hartung-Knapp meta-analysis,
  prediction intervals, and leave-one-cohort-out sensitivity analysis.
- Executed five-cohort PDAC/GPRC5A reference benchmark covering 481 patients,
  304 events, and 23 frozen validation checks.

### Scientific boundary

- Reference validation is computational, not clinical validation.
- Five additional multimodal workflow cards remain design contracts.
